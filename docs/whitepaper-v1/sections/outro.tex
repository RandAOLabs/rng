\section{Outro}\label{sec:outro}

This whitepaper has outlined the ``\textbf{Onchain Randomness Problem}'' and demonstrated how current solutions have made compromises in decentralization and security, leading to unsustainable centralization and denial of service attacks. 

We introduced the novel RandAO protocol, which solves the onchain randomness problem through an any-honest open access randomness provider network. The protocol's innovative design ensures that as long as a single provider remains honest, the system maintains its security and integrity.

The \$RNG token serves as the protocol's utility token for purchasing random values, creating a supply and demand driven economy to serve the outlined applications. This economic model aligns incentives between providers and users while ensuring the protocol's long-term sustainability.

With the RandAO protocol in place, fully decentralized onchain randomness will be readily available for all applications, enabling a new generation of secure and trustless Web3 services.
