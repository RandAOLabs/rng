\section*{Abstract}
We present RandAO, a decentralized random number generation protocol for AO and HyperBEAM whose output stays unpredictable as long as a single participating validator is honest. Every validator commits a time-lock puzzle whose answer is fixed the moment it is posted but cannot be computed by anyone else before the commitment window closes. Validators then reveal their answers together with the puzzle's one-time trapdoor, which lets the node verify each answer with a single modular exponentiation; a validator that withholds is cracked by the others, who prove their work with a short Wesolowski proof. Withholding therefore cannot bias or block a result; it can only delay it. Verification runs inside the node through the \texttt{timelock@1.0} HyperBEAM device, which removes the verifier fleet of our first version and brings a round down to two messages per validator. The protocol ships inside a single client library that also offers a free local tier and a fast threshold-signature tier, so applications pick the security they need per call. Requests are paid in the \$RNG token: one token to each validator that served a request and one to the protocol.
